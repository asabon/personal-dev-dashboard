# 🗺 開発ロードマップ & 実装実績 (`docs/dev/roadmap.md`)

Personal Dev Dashboard の機能開発マイルストーンおよび今後の拡張アイデアの一覧です。
本プロジェクトは、個人開発者が真に必要とする機能を段階的に実装し、すべての基本マイルストーン（Phase 1 〜 3）を達成しました。

---

## 🏆 実装実績 (Completed Milestones)

### Phase 1: MVP（コア機能）- ✅ 完了
- [x] **基盤構築**: Vite + React 19 + TypeScript (strict) + Tailwind CSS v4 の SPA 基盤
- [x] **Zero-Backend / BYOK**: ブラウザ内 `localStorage` 完結の PAT 永続化と直接 GitHub API 通信
- [x] **オンボーディング**: 初回アクセス時のトークン入力ダイアログ & 検証
- [x] **Actions 無料枠使用量カード**: GitHub Billing API（REST）による月間 2,000 分のリアルタイム消化率・残量表示
- [x] **PR × CI ステータス一覧**: GitHub GraphQL API (`statusCheckRollup`) によるリポジトリ横断の Pull Request 一括監視

### Phase 2: UX・運用改善 - ✅ 完了
- [x] **CI/CD 自動化**: GitHub Actions による PR 自動検証 & GitHub Pages 静的デプロイ
- [x] **自動更新ポーリング**: 設定モーダルでの自動更新間隔（手動 / 30秒 / 1分 / 5分）切り替え
- [x] **ワンクリック追加機能**: ログインユーザーがアクセス可能なリポジトリ（Private/Public）一覧からの即時追加・解除、インクリメンタル検索、種別フィルター
- [x] **レートリミット可視化**: ヘッダーでの API 残数バッジ & ツールチップ表示
- [x] **リリース自動化**: Release Drafter 連携によるタグ駆動の自動デプロイ & 正式リリース公開フロー

### Phase 3: インフラ連携 & 拡張 - ✅ 完了
- [x] **Self-hosted runner の稼働状況サポート（オプトイン）**:
  - 自宅 PC や自前サーバー等の死活ステータス（Online / Busy / Offline）を一括監視する集約パネル
  - アコーディオン開閉によるコンパクト表示
  - `[🏢 Org: xxx (共有)]` と `[📁 Repo: xxx (専用)]` のスコープ色分け表示
- [x] **所属 Organization の自動検知 & 選択**:
  - ユーザーが所属する Organization を自動検知し、チェックボックスで監視対象 Org をオンオフ可能
  - Org 配下のリポジトリをダッシュボードに登録していなくても Org 共有ランナーを直接監視可能
