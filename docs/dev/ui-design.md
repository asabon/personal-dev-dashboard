# UI / UX 設計案 (UI Design)

## 1. デザインコンセプト

- **Developer First & Dark Mode**: 開発者が常時サブモニターや片隅に表示しておきたくなる、洗練されたモダンなダークテーマUI。
- **Glanceable (一目でわかる視認性)**: 数秒見るだけで「Actions無料枠の残量」「今動いているCI」「落ちているPR」を瞬時に認知できる情報レイアウト。
- **Zero Configuration Friction**: トークン入力とリポジトリ追加が直感的に行えるオンボーディング体験。

## 3. コンポーネント構成

### 3.1 ヘッダー (`Header`)
- タイトル & バージョン表示
- GitHub API レート制限残数バッジ（例: `Remaining: 4890/5000`）
- 手動リフレッシュボタン（スピナーアニメーション付き）
- 自動更新トグル（OFF / 30秒 / 1分 / 5分）
- 設定モーダル起動ボタン（⚙️ アイコン）

### 3.2 Actions 使用量カード (`ActionsUsageCard`)
- 2,000 分のうちの現在使用分数
- プログレスバー（80%以上でイエロー、95%以上でレッドに変色）
- OS ごとの使用量 breakdown（Ubuntu / macOS / Windows）
- 請求サイクル終了日（リセット予定）

### 3.3 リポジトリ一覧 (`RepoList` & `RepoCard`)
- 監視中リポジトリを折りたたみ可能（アコーディオン）またはグリッドで表示。
- 各リポジトリのステータスバッジ（PR数、全体のCI健全性）。
- リポジトリの追加・削除・並び替えボタン。

### 3.4 PR アイテムカード (`PullRequestCard`)
- PR 番号、タイトル（GitHub 公式への直接リンク）、作成者、更新日時
- ブランチ名と最新コミットの短縮 SHA
- **CI ステータス統合バッジ**:
  - ✅ **All checks passed**
  - ❌ **Checks failed** (クリックで失敗したジョブのログ URL へ)
  - ⏳ **Checks in progress**
- 個別チェックの詳細展開ポップオーバー / バッジリスト

### 3.5 設定モーダル (`SettingsModal`)
- **GitHub PAT 入力フォーム**:
  - 現在設定されているトークンのマスク表示
  - トークン更新 / 削除（ログアウト）ボタン
  - 「必要な権限付きトークンを生成する」GitHub公式へのディープリンク
- **監視リポジトリ管理**:
  - `owner/repo` 入力で追加
  - ドラッグ&ドロップまたは削除ボタン
- **更新間隔設定**: 30秒 / 60秒 / 5分 / 手動のみ

### 3.6 オンボーディング画面 (`WelcomeScreen`)
- トークンが `localStorage` に未設定の場合に自動表示される初期画面。
- なぜ安全なのか（BYOK・localStorage 保存）の説明。
- トークン作成のガイドと入力欄。
